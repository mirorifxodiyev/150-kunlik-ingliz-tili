# 150-Kunlik Ingliz Tili Platformasi (American English Mastery)

AQSHga ko'chib o'tayotgan o'zbek tilida so'zlashuvchi kattalar uchun A0 (boshlang'ich) darajadan B1/B2 gacha bo'lgan to'liq 150 kunlik (kuniga 5 soatdan, jami 750 soat) oflayn o'quv platformasi.

## 🚀 Imkoniyatlar

- **150 Kunlik To'liq Dastur:**
  - 1-oy: A1 Poydevor (Alifbo, tovushlar, to be, asosiy fe'llar, Present Simple)
  - 2-oy: A2 Kundalik Muloqot (Supermarket, restoran, transport, Past Simple, Going to)
  - 3-oy: A2 -> B1 Amaliy Mustaqillik (Ish qidirish, suhbatlar, bank hisoblari, kvartira ijarasi, 911)
  - 4-oy: B1 Tinglash va Gapirish (Podkastlar, bog'langan nutq, STAR usuli, ish majlislari)
  - 5-oy: B1 -> B2 Rivojlanish va AQSH Hayoti (Kredit reytingi, ipoteka, tibbiyot hisob-kitoblari, diplomatiya)
- **Har kungi 5 soatlik amaliy mashg'ulotlar:**
  - 1-soat: Yangi lug'at va talaffuz (Web Speech API audio, IPA)
  - 2-soat: Grammatika va qoidalar tahlili
  - 3-soat: Tinglash va jonli kundalik Amerika dialogi
  - 4-soat: Yozish va amaliy topshiriq (avtomatik saqlanuvchi konspekt)
  - 5-soat: Og'zaki nutq va 8 savollik interaktiv kunlik test
- **SRS Interval Takrorlash tizimi:** (+1, +3, +7, +14, +30 kun)
- **Xatolar daftari:** Ketma-ket 3 marta to'g'ri topilguncha mustahkamlash
- **Nazorat testlari:** 20 ta haftalik test (16 savol) va 5 ta oylik katta imtihon (30 savol)
- **100% Oflayn va Xavfsiz:** Ma'lumotlar localStorage'da saqlanadi, JSON eksport/import mavjud.
- **Mustaqil HTML Eksport:** Sozlamalar bo'limidan bitta mustaqil `.html` fayl qilib yuklab olish imkoniyati.

## 🛠 Texnologiyalar

- React 19 + TypeScript
- Vite 8 + Tailwind CSS 4
- Lucide React (ikonkalar)
- Web Speech API (`en-US` audiosi)

## 💻 Mahalliy o'rnatish va ishga tushirish

```bash
# 1. Bog'liqliklarni o'rnatish
npm install

# 2. Dasturchi serverini ishga tushirish
npm run dev

# 3. Ishlab chiqarish (production) versiyasini yaratish
npm run build
```
